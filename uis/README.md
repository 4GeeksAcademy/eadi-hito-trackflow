# UIs

## `incident-manager`

`uis/incident-manager` es la ruta canónica de la interfaz de incidencias. Es un enlace simbólico hacia `auth-fullstack/frontend`, donde vive la aplicación Next.js activa y se conservan las rutas existentes de autenticación, operaciones y proveedores.

```bash
cd uis/incident-manager
npm run lint
npm run build
```
