# Services

Los servicios backend de TrackFlow deben vivir aquí, separados de las aplicaciones de `uis/`.

Cada servicio futuro debe documentar su contrato, variables de entorno, comando de validación y dependencia con los sistemas de almacén, ERP o transportistas que integre. En este hito no se añade un servicio ejecutable: las UIs usan datos de demostración claramente identificados.
